# Jellibi Robot Contest

국제로봇콘테스트에서 사용한 종목1, 종목2와 종목2 모터·리프트 보정용 Arduino 스케치입니다.

종목별 스케치 폴더를 정리하고 공개용으로 실제 RFID 카드 UID와 카드 식별자 출력 코드를 제거했습니다. 주행 경로, 모터·센서·리프트 설정은 유지했습니다. RFID로 출발하려면 아래 안내에 따라 본인 카드 UID를 로컬에서 설정해야 합니다. [변경 및 검증 내역](docs/SOURCE_VERIFICATION.md)

각 스케치는 독립적으로 업로드합니다. 세 `.ino`를 하나의 스케치 폴더에 합치지 마세요. 주 스케치 파일과 그 파일이 들어 있는 폴더의 이름이 일치해야 합니다. [Arduino 공식 스케치 규칙](https://docs.arduino.cc/arduino-cli/sketch-specification/)

## 스케치별 동작

| 스케치 | 용도 및 시작·종료 |
| --- | --- |
| Mission1 | 외부 T2에서 H2 방향으로 출발하여 고정 경로를 주행합니다. H6 아래 외부 T6 검출 시 즉시 정지하고 2.3초 대기합니다. RFID로 시작하고 A3 LOW 입력으로 주행을 중단합니다. |
| Mission2 | 외부 T5에서 H5 방향으로 출발합니다. 장애물 통로를 탐색하여 A6 외부 상차 → H2 외부 하역 → A4 외부 상차 → H6 외부 최종 하역 후 정지합니다. RFID로 시작합니다. |
| Mission2Calibration | 직진·좌우 회전·유턴과 리프트를 시리얼 명령으로 시험합니다. 라인트레이싱, RFID, 자동 반복은 없습니다. |

종목2는 D4부터 D6 고정 장애물, D1부터 D3 중 하나의 장애물, D7부터 D8 중 정확히 하나의 장애물을 전제로 합니다. D7이 막혀 있으면 D8을 추가 측정하지 않고 통과 가능한 것으로 간주합니다.

종목1·종목2는 실행 종료 후 리셋해야 다시 시작합니다. 종목2에는 종목1의 A3 정지 입력이나 calibration의 `s` 명령 처리가 없습니다. 종목2의 리셋은 스케치를 다시 시작하며, 독립적인 비상정지 기능은 아닙니다.

## 준비 및 Arduino IDE 사용

- 코드 기준 대상은 A6/A7 아날로그 입력이 있는 Arduino Nano 계열 보드입니다. 실제 보드 모델과 프로세서/부트로더 설정을 확인하세요.
- 종목1: `SPI`, `MFRC522` 라이브러리를 사용합니다.
- 종목2: `SPI`, `MFRC522`, `Servo` 라이브러리를 사용합니다.
- Calibration: `Servo` 라이브러리를 사용합니다.
- `Arduino.h`와 `SPI`는 해당 보드 패키지에서 제공됩니다. Arduino IDE 라이브러리 관리자에서 `MFRC522`와 `Servo`를 설치하세요. 원본에는 라이브러리 버전이 고정되어 있지 않습니다.

1. 사용할 폴더 안의 동명 `.ino`를 엽니다. 예: `Mission1/Mission1.ino`.
2. 실제 보드에 맞는 보드, 프로세서 및 포트를 선택합니다.
3. **검증**으로 컴파일한 후 보드에 **업로드**합니다.
4. 시리얼 모니터를 **9600 baud**로 설정합니다.
5. 종목1·종목2는 지정 위치와 방향에 로봇을 두고 등록된 RFID 카드를 인식시킵니다.

`HOST_SIM`, `M2_ROUTE_TEST`는 원본에 남아 있는 외부 시험용 조건부 코드입니다. 일반 Arduino IDE 업로드에서는 정의하지 않습니다. 해당 시뮬레이터와 과거 시험 보고서는 이번 첨부파일에 포함되어 있지 않습니다.

### 코드에 정의된 주요 핀

| 기능 | 핀 | 적용 |
| --- | --- | --- |
| 왼쪽/오른쪽 모터 PWM | D5 / D6 | 전체 |
| 왼쪽/오른쪽 모터 방향 | D7 / D8 | 전체 |
| 왼쪽/오른쪽 바닥 IR | A6 / A7 | 종목1·2 |
| RFID SS / RST | D2 / D4 | 종목1·2; SPI 선은 실제 보드 핀에 맞춰 연결 |
| 부저 | D3 | 종목1·2 |
| 정지 버튼 | A3, INPUT_PULLUP, LOW 시 눌림 | 종목1 |
| 전방 센서 | A0 | 종목2 |
| 리프트 서보 | D9 | 종목2·Calibration |

이 표는 소스의 핀 할당이며 전체 전원·배선도는 아닙니다.

## Calibration 사용법

시리얼 모니터의 줄 끝을 **Newline** 또는 **Both NL & CR**로 설정합니다. 소문자 동작 명령과 대문자 설정 명령을 구분합니다.

1. 빈 차는 `e`, 적재 시험은 팔레트를 수동 배치한 다음 `b`를 전송합니다.
2. `READY`가 나온 뒤 동작 명령을 하나씩 전송하고 이동 거리·각도를 측정합니다.
3. 설정을 조정하여 반복하고, 리셋 전에 `?` 출력값을 별도로 기록합니다.

| 명령 | 동작 |
| --- | --- |
| `e` / `b` | 빈 차 프로필·리프트 55도 / 적재 프로필·리프트 170도 선택 |
| `f` | 직진 |
| `a` / `d` / `u` | 좌회전 / 우회전 / 왼쪽 유턴 시험 |
| `s` 또는 `S` | 모터 정지, 진행 중 서보 이동 중단. 서보는 마지막 명령 위치를 유지 |
| `?` / `h` | 설정 표시 / 도움말 |
| `L 120` / `R 120` | 선택 프로필의 좌·우 PWM 설정 |
| `T 1000` | 직진 시간(ms) 설정 |
| `P 100` | 회전 PWM 설정 |
| `A 460` / `D 460` / `U 900` | 좌·우·유턴 시간(ms) 설정 |

PWM 범위는 0부터 255, 시간 범위는 10부터 5000ms입니다. 동작 중에는 정지 명령만 처리합니다. 설정은 RAM에만 저장되므로 리셋/전원 차단 시 사라지며, 종목1·2로 자동 반영되지 않습니다. 서보 55/170도와 회전 시간은 명령값이며 실제 위치·각도를 측정하는 피드백이 아닙니다.

Calibration은 좌·우 PWM을 직접 사용하지만 미션의 전진 코드는 왼쪽 출력에 비율을 적용합니다. 측정값을 미션으로 옮길 때 단순히 숫자를 그대로 복사하지 말고 해당 비율과 적재 상태를 함께 확인해야 합니다.

## 원본의 설정과 검증 범위

- 종목1 기본 순항 PWM은 207, 왼쪽 전진 비율은 182/207, 회전 PWM은 127이며 좌/우/유턴 시간은 350/360/690ms입니다.
- 종목2 실제 상수는 빈 차 순항/접근/복구 170/125/100, 적재 순항/접근/복구 100/90/100입니다. 
- Calibration 기본 프로필은 빈 차 L120/R120, 적재 L100/R100이며 미션의 최종 설정과 동일하지 않습니다. 초기 시험값입니다.


## RFID 시작 카드 설정

공개본은 실제 카드 UID 대신 0으로 채운 자리표시자를 사용합니다. `RFID_UID_CONFIGURED = false`이므로 어떤 카드를 대도 주행을 시작하지 않습니다.

1. 로컬의 `Mission1.ino`에서 `allowedUid`, `Mission2.ino`에서 `uid` 배열에 본인 카드의 4바이트 UID를 입력합니다.
2. 사용할 스케치에서 `RFID_UID_CONFIGURED`를 `true`로 바꿉니다.
3. 해당 스케치를 보드에 업로드합니다. UID가 일치하는 카드만 출발시킵니다.

실제 UID를 입력한 로컬 파일은 GitHub에 다시 올리지 마세요. 공개할 때는 배열을 0으로 되돌리고 설정 플래그도 `false`로 되돌립니다. 종목1의 카드 UID 시리얼 출력도 제거했습니다. Calibration은 변경하지 않았습니다.
